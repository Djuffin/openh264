# What `port_census.py` finds missing, and why — Phase 8b session A (T8b.A2).
#
#   format:  <key> | <class> | <evidence>
#     key    `name <CppName>`   one function, by name (wins over a file rule)
#            `file <path>`      every missing row in that C++ file
#     class  dead | renamed | missing
#
#     dead     the reference itself cannot reach it in the configuration this port
#              ships: no caller, SIMD-only, `#ifdef`-debug-only, or on the threaded
#              detour the plan deletes (D3/D-mt-1). Nothing to port.
#     renamed  ported under another name, or folded into a neighbour. The evidence
#              names the Rust site.
#     missing  a real gap. The evidence names the owner and the size.
#
# `port_census.py --classify` re-runs the census against this file and prints every
# missing row that has no rule — which is the point: the next unported function
# shows up as "unclassified", not as a surprise four phases later. The classes are
# summed into `docs/phase8b_port_census.md`.
